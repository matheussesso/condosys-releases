# condosys — instaladores

Este repositório guarda só os instaladores do condosys para Windows e os arquivos usados
pela atualização automática (`latest.yml` e `.blockmap`). O código fica em outro
repositório.

## Instalar

1. Abra a última versão em [Releases](../../releases/latest).
2. Baixe `condosys-instalador-<versão>.exe` e rode. Não precisa ser administrador.

Depois de instalado, o condosys se atualiza sozinho a partir daqui.
